# Hi, I'm Ryan 👋

**Backend developer with real ERP experience.** For 2+ years I've been shipping fixes and features to a production Oracle ERP used by companies in manufacturing, distribution, retail, services and education. Now I'm also building with **Node.js**, **C#** and **AWS**.

📍 São Bernardo do Campo, Brazil · 🌎 Open to remote roles, in Brazil and abroad · 🗣️ Advanced English

## What I bring

- **Production database work:** Oracle 19c PL/SQL packages, triggers and views, plus Oracle Forms and Reports screens, in an ERP that covers invoicing, payables and receivables, inventory, purchasing, tax and payroll.
- **Root cause, not workarounds:** I trace customer tickets down to the database and ship minimal, surgical changes to legacy code, with the original backed up and the test documented.
- **Business rules that are hard to get right:** Brazilian tax and banking formats (NF-e, CT-e, SPED, CNAB, ICMS-ST and the 2026 tax reform) as they actually run inside an ERP.
- **AI that is safe to put in a product:** I designed a natural-language query feature for the ERP where the model returns only validated filters, never free-form SQL.
